# 🎬 Movie App

A simple Movie App that displays films in **UI cards** with posters, ratings, and descriptions. Built using **HTML, CSS, and JavaScript**.

## 🚀 Features

- Responsive movie cards with hover effects
- Poster images, titles, ratings, and short descriptions
- Easy to extend with more movies
- Clean and modern UI

## 🛠️ Tech Stack

- **HTML5** for structure
- **CSS3** for styling and layout
- **JavaScript (ES6)** for dynamic rendering

## 📂 Project Setup

1. Clone the repository
2. Open `index.html` in your browser
3. Add more movies by editing the `movies` array in `script.js`

## 🎯 Future Enhancements

- Fetch movies dynamically from an API (e.g., OMDb, TMDb)
- Add search and filter functionality
- Include trailers and cast details
- Dark mode toggle
